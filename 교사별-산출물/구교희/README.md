## MAIL 필수 항목 보완

아래 내용은 HWPX 양식의 수업 설계·평가란을 보완하는 실행 기록이다. HWPX에는 차시별 수업 흐름과 평가 기준을, 이 README에는 적용 전 확인 사항·근거·기록 방법을 함께 보관한다.

### 학습자 분석

- 고2 미적분Ⅰ 학습자는 평균변화율 계산 경험은 있으나 도함수의 부호와 그래프의 증가·감소를 실제 의사결정 근거로 연결하는 데 어려움을 가질 수 있다.
- 계산 부담이 큰 학습자에게는 부호표와 ‘증가(+)-감소(-)-0인 후보’ 카드를 제공하고, 심화 학습자에게는 모델 가정과 실제 관찰값의 차이 및 시행 뒤 확인 지표를 제안하게 한다.

### 교육적 AI 근거

- AI는 정책 문장 다듬기와 반론 질문 초안 생성에만 보조적으로 사용하며, 수학적 계산·해석은 교사 제공 모델, 활동지, 교과서로 직접 검산한다.
- AI 활용 목적은 답안 대행이 아니라 모델의 가정·한계와 정책 근거를 비판적으로 확인하는 정보 활용 및 의사결정 역량 신장이다.

### 평가·자가평가

- 과정평가는 평균변화율 계산, 도함수 부호와 극값 후보 해석, 안전 기준 45명 이하 판정, 유휴 시간과 실행 가능성을 포함한 정책 근거를 관찰한다.
- 자가평가에는 ‘계산을 원자료와 대조했는가’, ‘가상 자료의 한계를 밝혔는가’, ‘AI 보조 내용을 검증·표시했는가’를 체크하고 정책의 한계를 한 문장으로 쓴다.

### 자료·보관 위치

- 1차시 교사 제공 가상 관찰표: `t=0, 2, 4, 6, 8, 10분`, 혼잡도 `8, 18, 38, 49, 31, 12명`. 실제 학생 자료가 아닌 평균변화율 탐구용 가상 자료이다.
- 2차시 교사 제공 가상 자료: `D(t)=-2(t-5)^2+50` (0≤t≤10, t는 분), `D'(t)=-4(t-5)`, 안전 기준 최대 45명 이하, 후보 시뮬레이션 비교값은 HWPX 2차시 활동지와 `content.py`에 보관한다.
- 수업 결과물은 식별 정보를 제거한 뒤 학교 승인 저장소의 해당 학급 수업 폴더에 보관하며, 원자료·AI 대화 전문·개인 식별 가능 자료는 공유 산출물에 포함하지 않는다.

### 프롬프트 기록

- 권장 프롬프트: ‘교사 제공 가상 모델 D(t)=-2(t-5)^2+50과 D'(t)=-4(t-5)를 바탕으로, 안전 기준 45명 이하와 후보별 최대 혼잡도·유휴 시간을 비교할 때 확인할 반론 질문 3개를 제안해 줘. 계산값은 새로 만들지 말고 근거를 구분해 줘.’
- 사용 모둠은 프롬프트, 응답 요약, 채택/수정 내용, 검증 출처(교사 제공 모델·활동지·교과서), ‘AI 보조 사용(도구명, 목적)’ 표시를 활동지와 발표 자료에 남긴다.

### 예상 질문·장애 대응

- ‘D'(5)=0이면 항상 최대인가?’에는 부호가 양수에서 음수로 바뀌고 그래프가 아래로 열린다는 점을 확인시킨다.
- ‘왜 3분안을 고를 수 있는가?’에는 최대 44명으로 안전 기준을 충족하면서 4분안보다 유휴 시간 3분이 짧다는 비교표 근거를 사용하게 한다.
- 기기·AI 접속 장애 시 인쇄한 함수·부호표·후보 비교표로 동일 활동을 진행하며, 계산 어려움에는 예시 한 구간과 부호표 완성 틀을 제공한다.
