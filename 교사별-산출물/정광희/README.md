## 적용 전 교사 확정 사항

- 날짜·교시, 수업 장소, 스마트패드·GeoGebra/Desmos·wifi-coverage-explorer 사용 환경과 모둠 편성을 확정한다.
- 학교별 가상 좌표 평면도, 가상 공유기 후보·반지름, 공동 문서 운영 방식 및 실제 정보 차단 절차를 확정한다.
- 실제 수업 전 학교 교육과정 문서와 성취기준·단원 편성을 대조한다. 위 학년·과목·단원·주제·성취기준은 본 산출물의 확정 내용이다.

## 개인정보·AI 검증 주의

- 학교명, 실제 공유기 위치, SSID, 비밀번호, 접속 기록 등 네트워크 보안정보와 개인정보를 수집·입력·공유하지 않는다.
- 가상 좌표만 사용하며, AI 계산과 설명은 거리 제곱·원의 방정식·그래프로 직접 검산하고 반영 이유를 기록한다.
- 결과는 가상 수학 모델의 개선안이며 실제 네트워크 성능·설정 변경은 관련 담당자의 검토 없이 실행하지 않는다.

## MAIL 필수 항목 보완

- **학습자 분석**: 고1 학생이 원의 표준형과 점의 위치 판단을 연결하는 데 어려움을 보일 수 있으므로, 중심·반지름 색 구분 활동지, 거리 제곱 비교표, GeoGebra/Desmos 입력 예시를 제공한다. 빠른 모둠은 후보별 교점과 새 사각지대까지 비교한다.
- **AI 근거**: 생성형 AI는 자료 목록 점검, 후보 장단점 설명, 표현 개선을 위한 보조 도구로만 사용한다. 중심·반지름·점의 위치 관계 판단은 학생이 거리 제곱 계산과 GeoGebra/Desmos 그래프로 검증하며, `wifi-coverage-explorer`는 결과 교차확인용으로만 사용한다.
- **평가/자가평가**: 과정중심평가에서 원의 방정식, 원·직선 위치 관계, 후보 B·C 비교 근거, AI 검증 기록을 관찰한다. 개인 성찰지에는 모델의 한계, AI가 도움 된 점, 직접 수정·검증한 점, 최종 선택 근거를 기록한다.
- **자료/보관**: 가상 좌표 평면도, 활동지, 커버리지 지도, 모델링 보고서, 발표 자료, AI 활용 기록지, 동료·갤러리 피드백, 성찰지를 공동 문서에 보관한다. 실제 학교 네트워크 정보는 보관하지 않는다.
- **프롬프트**: AI 활용 기록지에 사용한 프롬프트와 응답 요약, 채택·수정 내용 및 이유, 검증 출처(거리 제곱 계산, GeoGebra/Desmos 그래프 등), `AI 보조` 표시를 남긴다. 예: `후보 B(7, 3)와 C(9, 5), 반지름 6의 커버리지 차이를 설명해 줘. 단, 계산식도 제시해 줘.`
- **질문/장애대응**: “점이 원 안에 있는지 어떻게 판단하는가?”, “직선과 원의 교점 수는 무엇을 뜻하는가?”를 핵심 질문으로 사용한다. 기기·인터넷 장애 시 인쇄 활동지와 계산기로 거리 제곱 및 교점 판단을 진행하고, 교사가 제공한 화면 캡처로 그래프 결과를 대체한다.
