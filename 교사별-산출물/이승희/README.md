## HWPX와 README의 관계

- 두 HWPX는 수업에서 사용하는 1·2차시 지도안이며, `content.py`의 내용으로 생성한다.
- 이 README는 HWPX에 모두 담기 어려운 MAIL 필수 보완 사항, 운영 규칙, 적용 전 확인 사항을 함께 기록하는 문서이다.
- 실제 운영 시 HWPX의 수업 흐름과 이 README의 안전·평가·보관 규칙을 함께 적용한다.

## 적용 전 교사 확정 사항

- 날짜·교시, 교실·기기 환경, 앱 접속 주소·QR, 모둠 편성 및 교사 승인 비민감 자료 주제를 확정한다.
- 학교별 동의·응답 거부 안내, 자료 수집·보관·삭제 방식, 앱 운영 가능 여부와 대체 가상 자료를 확정한다.
- 실제 수업 전 학교 교육과정 문서와 성취기준·단원 편성을 대조한다. 위 학년·과목·단원·주제·성취기준은 본 산출물의 확정 내용이다.

## 개인정보·AI 검증 주의

- 이름 칸에는 실명이 아닌 교사가 배부한 일회용 별칭만 입력한다. 현재 앱은 실명 입력을 기술적으로 차단하지 못하므로, 이는 교사 감독 아래 적용하는 운영 규칙이다.
- 실명, 성적, 건강, 가정 형편, 몸무게 등 개인정보·민감 정보는 사용하지 않으며 응답하지 않음에 임의의 0을 입력하지 않는다.
- `/teacher` 교사 화면은 수업 교사만 접근하며 학생에게 URL·화면·인증 정보를 제공하지 않는다. 보관 책임자는 수업 교사이고, 수업 종료 직후 필요한 결과를 내보낸 뒤 서버 자료를 삭제한다.
- 앱 자동 추천과 AI 응답은 정답이 아니다. 원자료, 정렬·빈도, 극단값·반복값, 자료 목적을 학생이 검산·판단한다.
- AI 사용 시 프롬프트, 응답 요약, 채택·수정 내용, 검증 출처(원자료·교과서·활동지), `AI 보조` 표시를 활동지에 남긴다. AI 문장은 그대로 제출하지 않고 학생의 계산과 근거를 자신의 말로 작성한다.

## MAIL 필수 항목 보완

### 학습자 분석

- 중학교 1학년은 평균을 언제나 대표값으로 선택하거나 중앙값과 최빈값의 적용 조건을 혼동할 수 있다. 1차시 가상 자료와 정렬표·빈도표로 기초 계산을 확인한 후 2차시 디지털 도구 검증으로 연결한다.
- 기기 활용과 통계 경험의 차이를 고려하여 기록자·계산 검증자·기기 담당·발표자 역할을 나누고, 입력이 어려운 학생은 익명 예시 자료와 교사·또래 지원으로 참여한다.

### AI 근거

- AI와 앱의 자동 추천은 대푯값 판단을 비교·비판하는 보조 도구로만 사용한다. 최종 판단은 원자료, 정렬·빈도, 극단값·반복값, 자료 목적 및 교과서 개념으로 검증한다.
- 생성 결과를 사용한 모둠은 프롬프트와 응답 요약, 채택·수정 내용, 검증 출처, `AI 보조` 표시를 남겨 판단 과정을 추적할 수 있게 한다.

### 평가·자가평가

- 과정중심평가로 모둠의 탐구 문제·조사계획(대상·변수·단위·수집 방법·응답 거부·예상 자료 특성), 입력 정확성, 자동 추천 검증, 근거 기반 해석·협업을 관찰한다.
- 출구 티켓에서 학생은 ‘다음 분석에서 개선할 입력 또는 판단 한 가지’를 쓰고, 모둠은 선택한 대표값·근거·한계·생활 제안을 점검표로 자가평가한다.

### 자료·보관

- 교사 승인 비민감 주제만 사용하고, 수집 전 모둠별 조사계획을 교사가 확인한다. 응답 거부는 허용하며 결측을 0으로 대체하지 않는다.
- 보관 책임자는 수업 교사이다. 수업 종료 직후 필요한 결과만 내보내고 서버 자료를 삭제하며, 교사 화면 접근은 수업 교사로 제한한다.

### 프롬프트

- 예시: `다음 비민감 생활 자료에서 평균·중앙값·최빈값 중 무엇이 목적에 적절한지 설명하되, 원자료의 극단값·반복값·자료 유형과 한계를 함께 점검해 줘. 답은 교과서 개념과 원자료로 검증할 수 있게 써 줘.`
- 프롬프트에 실명, 민감 정보, 식별 가능한 서술을 넣지 않으며, AI 응답은 검증 후 자신의 말로 수정한다.

### 질문·장애대응

- 예상 질문: ‘응답하지 않음은 0인가요?’에는 ‘아니며 자료 수에서 제외하고 결측으로 기록한다’고 안내한다. ‘앱 추천이 항상 맞나요?’에는 원자료와 목적을 비교해 모둠이 판단한다고 답한다.
- 기기·네트워크 장애 시 교사가 준비한 익명 가상 자료, 인쇄 활동지, 계산기로 동일한 정렬·빈도·대푯값 검증 활동을 진행한다. 실명 입력 또는 민감 응답이 발생하면 즉시 삭제하고 일회용 별칭·비민감 주제로 다시 안내한다.
