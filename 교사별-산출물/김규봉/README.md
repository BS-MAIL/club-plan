# 김규봉 수업 산출물

| 항목 | 확정 내용 |
|---|---|
| 원 계획 근거 | `김규봉/생성형AI_CBL_수업설계_안전한학교_작성본.md`, `김규봉/안전한학교_세부문서/` |
| 학년 / 과목 / 단원 | 고등학교 1학년 / 공통수학2 / 도형의 방정식 |
| 주제 | 도형의 방정식으로 학교 소방·대피 안전망을 분석하고 개선안 제안하기 |
| 성취기준 | `[10공수2-01-03]` 점과 직선 사이의 거리, `[10공수2-01-04]` 원의 방정식, `[10공수2-01-05]` 원과 직선의 위치 관계 |
| 생성 HWPX | `도형의방정식_CBL_안전한학교_1차시.hwpx`, `도형의방정식_CBL_안전한학교_2차시.hwpx` |

| 차시 | 핵심 흐름 |
|---|---|
| 1차시 | 익명화한 약식 지도를 좌표화하고, 안전시설 접근 범위와 대피 동선을 원·직선으로 모델링한다. |
| 2차시 | 점-직선 거리와 원·직선 위치 관계로 사각지대를 분석하고, 수학적 개선안과 모델 한계를 공유한다. |

## 적용 전 교사 확정 사항

- 날짜·교시, 수업 장소(수학 교실 또는 컴퓨터실), 반·모둠 편성 및 기기·GeoGebra/Desmos 사용 가능 여부를 확정한다.
- 학교별 익명화 약식 지도, 좌표 축척, 안전시설·대피로의 가상화 범위, 활동지와 학교 안전 담당자 검토 절차를 확정한다.
- 실제 수업 전 학교 교육과정 문서와 성취기준·단원 편성을 대조한다. 위 학년·과목·단원·주제·성취기준은 본 산출물의 확정 내용이다.

## 개인정보·AI 검증 주의

- 학교명, 학생 정보, 사진, 정확한 내부 평면도·출입 제한 정보는 입력·공유하지 않고 익명화한 약식 자료만 사용한다.
- AI는 질문·점검 보조 도구로만 사용한다. 좌표, 계산, 방정식, 최종 판단은 학생이 직접 계산·그래프·토론으로 교차 검증하고 기록한다.
- 실제 안전 설치·운영 판단은 수학 모델 결과만으로 결정하지 않고 학교 안전 담당자와 관련 기준의 검토를 거친다.
- AI 활용 기록지에는 프롬프트, 응답 요약, 채택·수정 여부와 이유, 검증한 교과서·공식 자료 출처를 남기고, AI 생성 문장은 ‘AI 보조’임을 표시한다.

## 제출 규격 보완 정보

### 학습자 분석

- 대상은 공통수학2에서 점과 직선 사이의 거리, 원의 방정식, 원과 직선의 위치 관계를 학습 중인 고등학교 1학년이다.
- 좌표평면의 점·직선·원을 각각 표현할 수 있으나, 여러 식과 그래프를 실제 공간의 안전 문제로 연결하고 모델의 한계를 설명하는 데에는 비계가 필요하다.
- 모둠별 디지털 도구와 AI 활용 경험의 차이를 고려하여 좌표화, 거리 계산, 그래프 검증, AI 기록, 공유 역할을 순환 또는 분담한다.

### AI 활용 교육적 근거

- AI는 정답이나 개선 위치를 생성하는 도구가 아니라, 안전 사각지대 판단 기준과 발표 근거에서 추가 검증이 필요한 지점을 질문으로 점검하는 보조 도구로 사용한다.
- 학생은 AI 응답을 교과서 개념, 직접 대입 계산, GeoGebra/Desmos 그래프, 모둠 토론으로 교차 검증하여 수학적 추론과 정보 윤리를 함께 기른다.
- 익명화한 약식 지도만 사용하고 실제 설치 판단을 유보함으로써 개인정보 보호와 실제 안전 판단의 책임 범위를 학습한다.

### 평가와 자가평가

- 과정평가는 원점·축척 설정, 점-직선 거리와 원·직선 위치 관계의 적용, 계산-그래프-지도 맥락의 교차 검증, 모둠 협업과 AI 활용 기록을 관찰한다.
- 결과평가는 안전 분석 지도, 사각지대 분석표, 교사가 제공한 2개 개선 후보 중 선택한 제안서의 수학적 근거와 모델 한계, 대표 모둠 2개의 1분 피치 및 갤러리 피드백으로 확인한다.
- 자가평가는 개인 성찰지에 핵심 질문에 대한 현재의 답, 사용한 수학적 근거, AI 채택·수정 또는 미채택 이유, 개인정보 보호 실천, 모델의 한계와 추가 조사 필요 정보를 기록한다.

### 개발 자료와 보관 위치

- 개발 자료는 익명화한 학교 약식 지도, 좌표 격자 활동지, 사각지대 분석표, 교사 제공 개선 후보 카드 2종, 제안서·성찰지, AI 활용 기록지, GeoGebra/Desmos 그래프이다.
- 수업 설계 원본과 생성 HWPX는 `김규봉/` 폴더에, 세부 근거 자료는 `김규봉/안전한학교_세부문서/`에 보관한다. 학생 산출물은 개인정보를 제거한 뒤 학급 공유 공간에 보관한다.

### 구체적 AI 프롬프트

- `익명화한 좌표 지도에서 후보 P의 안전 사각지대 판단을 위해 점-직선 거리, 원의 방정식, 원과 직선의 위치 관계 중 무엇을 추가 검증해야 하는지 질문 3개만 제시해 줘. 계산값이나 개선 위치를 결정하지는 마.`
- `우리 모둠의 개선 후보 선택 근거를 검토할 질문을 제시해 줘. 교과서의 점-직선 거리와 원의 방정식 개념으로 직접 검증할 수 있는 질문만 작성하고, 실제 안전 기준을 단정하지 마.`
- 기록지에는 위 프롬프트, 응답 요약, 채택·수정 여부, 검증에 사용한 교과서 또는 학교·교육부 공식 자료 출처를 함께 남긴다.

### 예상 질문과 기술 장애 대응

- 예상 질문: ‘직선거리가 실제 대피 거리와 같은가?’에는 벽·계단·혼잡도 때문에 다를 수 있으므로 본 결과는 개선 후보이며 실제 판단은 안전 담당자와 공식 기준 검토가 필요하다고 안내한다.
- 예상 질문: ‘AI가 제안한 위치를 그대로 써도 되는가?’에는 AI는 질문·점검 보조이고, 학생이 계산·그래프·교과서 또는 공식 자료로 검증한 내용만 반영하며 AI 생성 문장은 ‘AI 보조’로 표시한다고 답한다.
- AI 접속 또는 기기 장애 시 교사가 준비한 검증 질문 카드와 개선 후보 카드 2종을 사용하고, 계산기·인쇄 활동지·교사 시연 GeoGebra 화면으로 동일한 분석을 진행한다.
- GeoGebra/Desmos 사용 장애 시 원의 중심·반지름과 직선 식을 좌표 격자 활동지에 직접 작도하고, 대입 계산과 거리 공식으로 결과를 검산한다.
